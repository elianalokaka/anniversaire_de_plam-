# 🎂 Surprise d'anniversaire pour Plamedi

Projet prêt pour GitHub Pages.

### Ce que fait la page
- Compte à rebours de 10 secondes.
- Une photo différente accompagne chaque nombre du décompte.
- Ouverture d'une enveloppe 💌.
- Lettre animée.
- Le texte fourni est conservé intégralement, sans condensation.
- Les emojis du texte bougent légèrement.
- Chaque clic sur la lettre déclenche une pluie de ❤️ 🌹 💋 🌸 ✨.
- Des petites animations continuent en arrière-plan.
- Bouton pour écouter **Goodbye Yellow Brick Road** d'Elton John via la publication YouTube officielle.

### Mettre en ligne avec GitHub Pages
1. Crée un dépôt GitHub, par exemple `anniversaire-plamedi`.
2. Téléverse `index.html` et le dossier `images`.
3. Va dans **Settings → Pages**.
4. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
5. Choisis la branche `main` et le dossier `/ (root)`.
6. Enregistre.
7. GitHub donnera une adresse du type :
   `https://TON-PSEUDO.github.io/anniversaire-plamedi/`

Tu pourras alors envoyer cette adresse à Plamedi : il l'ouvrira directement dans son navigateur.

### Musique
La chanson n'est pas copiée dans le projet. Le bouton ouvre la publication YouTube officielle de **Goodbye Yellow Brick Road — Elton John**, ce qui évite de redistribuer le fichier audio.
